project at:

    https://www.freertos.org/a00114.html

The full text of GPLv2 is bundled in this directory as `GPL-2.0.txt`.

Practical effect for this repository
------------------------------------
The exception permits distributing a combined work that includes the FreeRTOS
kernel together with components released under other terms (here: MIT for the
application code, BSD-3-Clause for ST HAL), without being obliged to publish
those components' source under the GPL. The FreeRTOS kernel source itself
remains under GPLv2 + exception.
